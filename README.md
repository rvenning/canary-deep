# Canary Deep 🐤

Minesweeper a thousand feet down a coal mine — where **no board ever needs a guess**.

**[Play it →](https://rvenning.github.io/canary-deep/)**

## The point of it

Ordinary minesweeper eventually corners you: two squares are symmetric, the
numbers say nothing, and a perfectly played board is decided by a coin toss.
Canary Deep never does that. Before a board is dealt, a solver plays it through
using logic alone — counting, subsets, the mines-remaining counter, and full
enumeration of the frontier. If the solver would ever have to guess, that board
is thrown away and another is cut. Whatever square you are stuck on, it *can* be
worked out.

That guarantee is what lets the deep shifts run at mine densities well past
classic Expert (20.6%) without becoming unfair — the last shift is 27% gas,
which is roughly where the generator runs out of fair boards altogether.

## Features

- **18 shifts across 3 seams**, from an 11%-gas day hole to a 27%-gas last
  shift, each unlocking the next. Three stars per shift.
- **No-guess boards, always.** Dealt on your first tap, with that tap as an
  input — so your opening square is safe *and* the board is solvable from it.
- **The bird in the cage.** One resource, two uses: send the canary ahead and it
  lands on a square you could already have proved safe, or leave it in the cage
  and it takes the hit the first time you tap gas — 15 seconds instead of the
  shift. Insurance or information, and you only get one.
- **Par computed from your board, not from a stopwatch.** Par comes from how
  many decisions the solver actually had to make, so a lucky board and an
  awkward one are graded on the same terms.
- **Press, slide, lift.** Nothing commits until you let go, so a 26px square on
  a phone is genuinely playable — you can see where you are about to dig.
- **Chording, marking, right-click**, and a mode toggle for thumbs.
- **A Daily Seam**: one board, one attempt, the same for everybody, with the
  opening square pre-dug so every run starts from the same hole.
- **Free Dig** in three sizes with a best time kept for each.
- Family profiles with PINs, a shared leaderboard, cross-device sync, and
  offline play as an installed app.

## Built on gamekit

Profiles, PINs, storage + Firestore family sync, the sound engine, screens,
canvas effects and PWA install all come from
[gamekit](https://github.com/rvenning/gamekit), vendored into `lib/`.

Re-vendor after a gamekit change:

```bash
node ../gamekit/tools/sync-to-game.js "../canary-deep"
```

Never edit `lib/` directly — the next sync overwrites it. Bump `CACHE` in
`sw.js` whenever any shell file changes, or installed devices keep serving the
old build.

## Layout

| Path | What it is |
|---|---|
| `js/board.js` | The grid: dimensions, mines, neighbour counts. Pure data. |
| `js/solver.js` | The deduction engine. Counting, subsets, the counter, enumeration. |
| `js/generate.js` | Deals a board and repairs it until the solver can finish it. |
| `js/shifts.js` | The 18 shifts, the free-play sizes, the Daily, par and stars. |
| `js/game.js` | The engine — digging, marking, chording, the canary, the clock. No DOM. |
| `js/render.js` | Canvas, input, the frame loop. |
| `js/main.js` | Screens and the app shell. |

## Local development

```bash
npx http-server . -p 8115 -c-1
```

Then open http://localhost:8115. There is no build step — plain `<script>` tags.

Tests (no framework, Node's built-in runner):

```bash
node --test
```

`tests/solver.test.js` proves the solver never deduces something false;
`tests/generate.test.js` deals every shift over many seeds and asserts each
board is solvable without a guess; `tests/bot.test.js` plays the whole campaign
headlessly to check nothing is unwinnable and that par is worth chasing;
`tests/storage.test.js` covers the cross-device merge.

## Storage

- localStorage prefix `cnry_`
- Firestore collection `canarydeep` in the shared `wordvoyage-e5a5c` project

The Firebase API key in `js/firebase-config.js` is a public client config, not a
secret — it is restricted to the Cloud Firestore API and the rules require an
anonymous sign-in.
